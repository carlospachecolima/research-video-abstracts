# research-video-abstracts
Research Video Abstracts: Bilingual repository of video abstracts for scientific publications and technological extension.
**Bilingual repository of video abstracts for scientific publications and technological extension.**
**Repositório bilíngue de vídeo-resumos de publicações científicas e extensão tecnológica.**

## 🎯 Objective / Objetivo
[EN] This repository centralizes the scripts, generative AI prompts (Gemini Notebook), and metadata used to create 8-minute technical video abstracts for my research papers. The final video files (.mp4) are permanently hosted on Zenodo to comply with FAIR and Open Science principles.

[PT] Este repositório centraliza os roteiros, prompts de IA generativa (Gemini Notebook) e metadados utilizados na criação de vídeo-resumos técnicos de 8 minutos para meus artigos científicos. Os arquivos finais de vídeo (.mp4) estão hospedados permanentemente no Zenodo, em conformidade com os princípios FAIR e de Ciência Aberta.

## 🗂️ Structure / Estrutura
Each publication has its own directory containing:
Cada publicação possui um diretório próprio contendo:
- `README.md`: Video script (EN/PT) and original prompts / Roteiros e prompts originais.
- `Zenodo_Link`: Direct DOI link to the hosted video / Link DOI direto para o vídeo.
